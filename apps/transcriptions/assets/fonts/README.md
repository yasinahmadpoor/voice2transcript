# Document export fonts

Vazirmatn v33.003, regular (400) and bold (700), from the official project:
https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/ttf

These unmodified TTF files include Persian/Arabic and Latin glyphs. They are
bundled and embedded in Word and PDF exports so generation works offline.
See OFL.txt for the SIL Open Font License and copyright notice.
